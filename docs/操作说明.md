# 操作说明

## 导入用户

CSV 必填列是 `user_id`、`email`、`consent`、`consent_reference`。`consent` 必须为 true，授权记录需要可追溯。其余可用列见 `src/agnes_provisioner/users.py` 的 `UserInput`，示例见 `examples/users.csv`。

同一用户重复导入会跳过；重复邮箱绑定不同用户会报告冲突。校验错误只显示行号和字段，不打印原始资料。密码、验证码、OAuth 令牌和 API Key 不应放入用户 CSV。

```powershell
uv run agnes --config config.local.toml import-users data/users.csv
uv run agnes --config config.local.toml create-batch first-batch --users user-001 user-002
```

真实模式会为新用户准备独立的随机 Agnes 密码并加密保存。它与邮箱登录密码分别管理。已确认账号的密码才会进入交付表。

### Web 智能导入与账号核验

上述 `import-users` 是不含凭证的基础资料 CSV。Web 导入向导另支持含凭证的本地文本或 CSV：

- 一至五段文本自动识别；四段为 `邮箱----邮箱密码----ClientID----RefreshToken`，三段为 `邮箱----邮箱密码----平台密码`，五段为 `邮箱----邮箱密码----平台密码----ClientID----RefreshToken`。
- 两段密码可以指定只用于邮箱、只用于平台，或同时使用。纯邮箱新注册会生成独立平台密码；已有账号必须提供平台密码或已在本地凭证库保存该密码，不会用随机密码尝试登录。
- CSV 至少需要 `email` 列，可加 `user_id,mailbox_password,agnes_password,client_id,refresh_token`；支持带引号的逗号、双引号及多行字段。密码、令牌写入 DPAPI 凭证库，不进入用户表或任务日志。导入文件本身含明文，应由持有人妥善保管。
- 粘贴、选择文件或拖入 `.txt/.csv` 后立即预览前 20 行并统计全量有效/异常行。先修正异常行再提交；服务端会再次严格校验并返回拒绝行号。重复邮箱更新凭证，不重复创建同一提供商的任务；已在其他批次的任务不会自动搬移。

选择“已有账号”后，新任务进入 `PENDING_VERIFY / REGISTRATION_SUBMITTED`，执行只登录核验与提取结果，不重新注册。任务大盘支持单条或批量核验及邮箱连接测试；跨批次选择时需先选择单一批次再批量登录核验。邮箱连接测试不改变注册状态。

批次自动核验默认跳过已有最终结果的账号；手动选中或点击单条“验证登录”可以重新检查这些账号的登录状态，不会重新注册或重复创建已保存的结果。

任务默认脱敏；复制会按需读取该单元格的完整凭证，不需要全局显示。右侧详情中的改密只更新本机凭证，留空保持原值，不会修改远端平台或邮箱密码。

### Web 流程编排与运行

九个节点按注册、登录、结果提取分组。点击节点展开参数，定位器可选择按钮文字、输入框提示词、高级 CSS/Playwright 或跳过。空选择器使用官方默认，`none` 明确跳过，二者不同。

每个节点后可插入动作，调整执行位置、上移/下移、启用/禁用；禁用的草稿仍会保存。先选择插入阶段，再调整该阶段内的顺序；不同阶段始终按固定生命周期顺序执行。`before_code` 是填写账密之后、发码之前，可用于勾选服务协议。登录阶段为 `before_open / before_fill / before_submit / after_submit`，结果阶段为 `before_navigate / before_extract / after_create / extract`。

正则测试器在浏览器中即时预览并高亮匹配，保存时由 Python 再次校验。结果来源可选页面文本、网络 JSON、剪贴板、LocalStorage 或自定义提取。严格身份核验要求邮箱和已登录标志同时匹配；Token 模式虽然内部名仍为 `url_or_token`，实际必须同时满足可信站点内离开登录页和非空 Token，单纯跳转不算登录成功。

人工验证码自动联动为可见浏览器。设置只影响下一次启动的任务，执行中需等待停止后再保存。恢复默认流程会要求确认并保留运行限制、数据库和凭证路径。

## 接收验证码

手动接收：设置 `manual_verification = true`、`headless = false`。浏览器填好邮箱并发送验证码后，在该用户的验证码框输入验证码，程序继续注册。等待时间由 `verification_timeout_seconds` 控制。

获准使用 Outlook 验证接口时，将四段资料放在本地 UTF-8 文件，每行格式为 `邮箱----邮箱密码----客户端ID----刷新令牌`，然后导入：

中文菜单的操作 11 可以导入这种文件，并记录本次邮箱授权说明。导入完成后，操作 3 创建批次，操作 4 执行，操作 6 导出 Excel。

```powershell
uv run agnes --config config.local.toml import-mailboxes data/mailboxes.txt --authorized --consent-reference 用户授权记录编号
uv run agnes --config config.local.toml mailbox-check 用户ID
```

邮箱接口使用已授权的 OAuth 权限，只读收件箱和垃圾邮件元数据，仅解析本次新到达、收件人与用户匹配、发件域属于 Agnes 的验证码邮件。邮件正文与验证码不会写入日志。

导入文件由用户管理，工具会把凭证另存到加密凭证库。普通用户 CSV、数据库和操作日志不保存邮箱密码或令牌。

## 运行、暂停和停止

```powershell
uv run agnes --config config.local.toml run first-batch
uv run agnes --config config.local.toml pause first-batch
uv run agnes --config config.local.toml resume first-batch
uv run agnes --config config.local.toml stop first-batch
```

控制命令在另一个终端执行。暂停会阻止后续提交，正在等待提交的浏览器保持打开，直到恢复。停止会停止后续任务并保存当前状态。已提交但无法确认结果的任务进入核查。

`resume` 用于仍在运行中的调度器；进程已经退出时使用 `run` 继续。每个数据库只允许一个调度器运行。

## 核验已有注册结果

```powershell
uv run agnes --config config.local.toml jobs --batch first-batch
uv run agnes --config config.local.toml verify-job 任务ID
```

如果已请求邮箱验证码、尚未提交创建账号，核验入口可以重新执行验证步骤。已经提交账号的任务只尝试正常登录和读取账号结果，不再次提交注册表单。

成功判定要求登录界面中的邮箱匹配当前用户，并且存在已登录界面标记。页面跳转本身不足以标记成功。`identity_navigation_selector` 可先打开个人资料；`account_identity_selector` 留空时匹配显示的完整邮箱。已登录标记应指向受登录保护的账户控件。请先用获授权的小批次核对当前平台页面与本地配置，再正式执行。

`key_flow` 启用后可进入 API Key 页面、填写密钥名称、创建并读取密钥。创建前保存任务边界；如果创建结果未知，程序不会自动再次创建密钥。页面只显示缩略内容时，`copy_selector` 指向当前用户命名的密钥行，通过页面复制动作取得完整密钥，随后清空剪贴板。已有密钥会保存在加密凭证库中，普通状态输出隐藏其值。

仅在已核查确定账号没有创建时重新排队：

```powershell
uv run agnes --config config.local.toml review-not-created 任务ID --evidence 核查记录编号
```

## 代理

编辑 `proxies.example.toml`，代理地址与认证环境变量引用分开填写。将真实配置保存为本地文件。

```powershell
$env:AGNES_PROXY_USERNAME = Read-Host 代理用户名
$taskProxyPassword = Read-Host 代理密码 -MaskInput
$env:AGNES_PROXY_PASSWORD = $taskProxyPassword
uv run agnes --config config.local.toml proxy-import data/proxies.toml
uv run agnes --config config.local.toml proxy-check approved-proxy-1
uv run agnes --config config.local.toml proxy-list
```

只有健康代理可以获得租约。同一任务的浏览器上下文保持同一代理配置；出口实际是否固定取决于提供商的 Sticky Session 配置。真实模式使用代理时须填写 `approval.proxies_allowed`。

支持 HTTP、HTTPS 和无需用户名密码的 SOCKS5。Chromium 不支持带用户名密码的 SOCKS5，此配置会直接报错。平台安全限制和邮箱域名限制会暂停对应批次。

Web 代理池支持 URL、`host:port:user:pass`、动态 `{session}` 隧道模板，预览不显示账密。新导入的内联认证通过当前 Windows 用户 DPAPI 加密保存；旧版明文节点仅兼容读取，显式重新导入该节点才升级加密，不会后台改写旧资料。

轮换策略可按结果次数、执行次数或二者先到的阈值触发。手动换轮只影响后续任务；静态代理是否真的换出口，取决于下一节点是否为不同 IP。动态代理刷新 Session 后需要重新检测才能确认新出口，界面不会把旧 IP 或旧延迟冒充为本轮测量。

“并发测速”最多同时检查 8 个节点并保存出口 IP 与延迟。运行中、测速中或已提交待核查任务保留绑定的节点不能手动轮换、删除或重置。提交前的 IP/网络故障可切到下一健康代理；提交后保留原绑定并先核查，不重复注册。重置为 HEALTHY 只是人工重置，不代表已实测通过。

## 备份和删除

停止调度器后备份：

```powershell
uv run agnes --config config.local.toml backup data/backup
```

备份包含数据库和加密凭证。加密凭证只能由保存时的 Windows 用户解密。数据库变化由内置 Alembic 迁移管理。

Web 的“交付导出与备份”提供同样的一致性备份入口，保存到配置目录的 `outputs/backups/时间戳/`。任务执行中会拒绝备份；导出默认不包含明文凭证，需要完整交付时显式勾选并确认。

删除一个用户的本地资料、任务、审计事件和凭证：

```powershell
uv run agnes --config config.local.toml delete-user 用户ID
```

本地删除不会修改 Agnes 上的账号。已导出的 Excel 和外部备份需要由持有人另行管理。
