# ISS-004：实现代理池可视化面板与“执行/达成结果满 X 次自动换 IP”轮换引擎

## 目标与范围

### 当前问题
用户在批量执行注册或更改后的流程时，单一 IP 很容易触发平台限流（`IP_REGISTRATION_LIMIT`）。用户需要能够方便地把一批代理导入代理池，并直观地设定和看到**“每用当前 IP 执行满 X 次注册流程（或者每成功达成 X 次想要的结果），就自动切换到下一个 IP”**，同时能随时查看每个代理的健康度、实测出口 IP 与当前轮计数进度。

### 期望行为
1. **可视化“满 X 次自动换 IP”策略控制台**：
   - 提供直观的策略模式卡片选择：
     - **🎯 达成结果计数模式 (`result_reached`)**：每用当前代理成功拿到 **X** 次最终想要的结果（如成功注册并提取到 API Key），立即自动切换到下一个代理 IP（或刷新隧道会话换新出口 IP）。
     - **🔢 执行流程计数模式 (`execution_count`)**：不管成功与否，每执行 **X** 次注册流程就自动切换到下一个 IP。
     - **⚡ 双重兜底模式 (`both`)**：达成 **X** 次目标结果 **或** 累计执行满 **Y** 次流程，满足任一条件立即换 IP。
   - **当前激活代理与换 IP 进度条卡片**：实时显示当前排在首位的代理节点 ID、实测出口 IP、当前轮次（Generation）、以及可视化的进度条（如：`本轮进度：1 / 2 次目标结果 —— 再达成 1 次将自动切换至下一节点`）。
2. **代理池批量导入实时预览与一键并发测速墙（参考 Clash Metacubexd）**：
   - 支持粘贴任意常见格式（`http://user:pass@host:port`、`host:port:user:pass`、`http://user-{session}:pass@host:port`、`socks5://host:port`）并在导入前实时预览解析出的协议、主机、端口、是否含认证、是否为动态会话模板。
   - 支持一键「并发检测全部代理连通性 & 查询真实出口 IP」，在代理列表/卡片上展示状态徽章、实测出口 IP、本轮进度条、历史总成功数，以及单节点「立即换下一轮」「启用/停用」「删除」操作。
3. **平台 IP 限制自动熔断与无缝切 IP**：
   - 当某代理触发 `IP_REGISTRATION_LIMIT` 或网络断连时，若开启了“遇 IP 限制自动切换下一个 IP”，调度器自动将该代理切入下一轮/标记异常，并把未提交的任务无缝交给池子里的下一个健康代理继续执行，不中断整批任务。

### 本次包含与排除的内容
- **包含**：自动换 IP 策略配置面板、当前 IP 进度可视化组件、代理批量导入解析预览、并发连通性与出口 IP 检测、手动/自动轮换与重置。
- **排除**：内置商业代理供应商充值计费接口（聚焦通用 HTTP/HTTPS/SOCKS5 代理池与动态 Session 隧道代理）。

## 必要设计与依据

- **交互参考**：
  - 参考 **Clash Metacubexd / Yacd 代理面板**：顶部为当前策略与激活节点状态大卡（含换 IP 倒计时进度条），下方为代理池节点矩阵/表格，支持一键全量测速与单点切换。
- **后端轮换算法依据（`src/agnes_provisioner/proxy.py` & `src/agnes_provisioner/scheduler.py`）**：
  - 每个代理维护 `ProxyMeta`：`generation`（当前轮次）、`window_results`（本轮已达成结果数）、`window_executions`（本轮已执行次数）、`session_sticky_id`（动态会话后缀）。
  - `ProxyManager.acquire()` 按 `(meta.generation, proxy.failures, proxy.id)` 排序选出最优健康节点；当本轮计数达到 `rotate_every`（X）时，`ProxyManager.release()` 自动将 `meta.generation += 1`、清零本轮窗口计数并重新生成 `session_sticky_id`，从而让下一次任务自动切换到下一个代理 IP。

## 验收方法

1. **代理批量导入与解析预览**：
   - 在代理导入框粘贴 `http://u1:p1@127.0.0.1:8001`、`127.0.0.1:8002:u2:p2`、`http://u3-{session}:p3@127.0.0.1:8003`，确认预览区正确识别出 3 条代理及第 3 条的“动态会话模式”标记；点击导入后列表立即显示 3 个节点。
2. **满 X 次自动换 IP 验证**：
   - 设置策略为“每达成 `2` 次目标结果换 IP”，启动包含 4 个账号的模拟或真实批次：
   - 观察前 2 个账号使用第 1 个代理，进度条从 `0/2` 变为 `1/2`，第 2 个完成后第 1 个代理轮次变为 `第 1 轮 (0/2)`，第 3、4 个账号自动切换到第 2 个代理执行。
3. **手动切 IP 与一键重置验证**：
   - 点击顶部“立即手动切换到下一个 IP”，确认当前激活代理立即顺延到下一个节点；点击“重置所有代理计数与健康状态”，所有节点恢复 `第 0 轮` 且状态为 `HEALTHY`。
