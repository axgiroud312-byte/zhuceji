# ISS-002：实现可视化注册流程与最终结果提取流程编排器（参考 Automa / n8n 步骤流）

## 目标与范围

### 当前问题
虽然底层 `config.py` 与 `agnes.py` 已经支持自定义选择器与 `custom_steps`，但前端界面如果只是罗列几十个 `*_selector` 文本输入框，用户很难直观看懂“整个注册和拿结果的过程到底先干嘛、后干嘛”，也不知道怎么在不懂 Playwright 语法的情况下修改按钮定位或插入新步骤。

### 期望行为
1. **可视化流水线卡片画布（Visual Pipeline Flow）**：
   - 将整个自动化流程以直观的**横向/纵向步骤节点链（Step Pipeline）**展示为三大阶段：
     - **阶段一：打开与注册提交 (`registration_flow`)**：`[1. 访问入口页]` ➔ `[2. 点击切换注册]` ➔ `[3. 填写邮箱与密码]` ➔ `[4. 发送并填写验证码]` ➔ `[5. 点击提交注册]`
     - **阶段二：登录与身份确认 (`login_flow`)**：`[6. 登录账号 & 确认身份]`
     - **阶段三：获取最终想要的结果 (`key_flow`)**：`[7. 进入结果页面]` ➔ `[8. 触发创建目标项]` ➔ `[9. 提取并保存最终结果 (正则匹配)]`
   - 点击任意步骤节点，展开该节点的配置卡片；在任意两个标准阶段之间可直接点击 **`+ 插入自定义动作`**（例如：在“填完账密后”插入“勾选服务协议复选框”，或在“点击提交后”插入“关闭新手引导弹窗”）。
2. **零门槛元素定位辅助器（Smart Selector Helper）**：
   - 用户修改任意按钮或输入框定位时，无需手写复杂语法，可通过下拉框选择定位方式：
     - `按按钮/链接文字`（填 `立即注册` 自动生成 `text="立即注册"`）
     - `按输入框提示词 (Placeholder)`（填 `请输入邮箱` 自动生成 `input[placeholder*="请输入邮箱"]`）
     - `按元素 ID / CSS 选择器`（如 `#keyName`、`.ant-modal .ant-btn-primary`）
     - `跳过此步 (none)`（例如页面打开直接就是注册表、或没有确认密码框时一键设为跳过）。
3. **最终结果（Result / Key）提取器可视化配置与正则实时测试器**：
   - 支持自由设置“最终想要的结果”是什么（如 `sk-...` API Key、JWT Token、邀请链接、积分余额等），提供常用正则模板一键填入（`OpenAI/Agnes 风格 sk- 密钥`、`JWT Token`、`6位数字码`、`任意非空文本`）。
   - 内置一个**“正则表达式实时测试小工具”**：用户粘贴一段网页文本或 JSON 示例，界面实时高亮显示按当前 `pattern` 能提取出什么结果，确保不跑空！
   - 支持自定义步骤的**上移 / 下移排序**、**启用 / 禁用开关**以及**一键恢复 Agnes 官方默认流程**。

### 本次包含与排除的内容
- **包含**：可视化三阶段流水线编辑器、插入/排序/开关自定义步骤、人性化选择器生成器、最终结果正则模板与实时匹配测试器、保存至 `config.local.toml` 及一键还原。
- **排除**：浏览器内嵌录制器插件（仅在 Web 控制台内完成可视化编排与校验）。

## 必要设计与依据

- **开源设计参考**：
  - 参考 **Automa（开源浏览器自动化工作流工具）** 与 **n8n / Dify**：左侧/上方为带连接线的步骤节点流（Step Nodes），每个节点清晰显示当前动作摘要（例如：`点击按钮：text="API 密钥"`、`正则提取：sk-[A-Za-z0-9_-]{16,}`），右侧或展开区为该节点的属性编辑面板。
- **数据模型依据（`src/agnes_provisioner/config.py` & `src/agnes_provisioner/agnes.py`）**：
  - 对应 `RegistrationFlow`、`VerificationFlow`、`LoginFlow`、`KeyFlow` 及其 `custom_steps: list[FlowStep]`。
  - `FlowStep` 支持动作：`click`、`check`、`fill`（支持 `{email}`、`{password}`、`{user_id}`、`{code}` 变量）、`wait_selector`、`wait_ms`、`goto`、`press`、`extract_text`、`extract_storage`、`evaluate_js`。

## 验收方法

1. **可视化节点流交互**：进入“流程编排”页面，能够清晰看到从“打开注册入口”到“提取最终结果”的完整步骤链；点击任意节点可编辑其参数，使用“按按钮文字”输入文字能自动生成对应选择器。
2. **自定义步骤增删与排序**：
   - 在注册流程中新增一条“填完账密后 ➔ 勾选复选框 `#agree-tos`”步骤，再新增一条“等待 500ms”步骤，点击上移/下移可调整顺序，点击保存并刷新页面后顺序与内容完整保留在 `config.local.toml`。
3. **最终结果正则实时测试**：
   - 在最终结果流程区修改正则 `pattern` 或选择预设模板，在“正则测试框”输入示例文本（如 `{"data": {"key": "sk-AbCdEf1234567890"}}`），界面立即高亮显示匹配到的 `sk-AbCdEf1234567890`。
4. **一键还原默认流程**：点击“恢复 Agnes 官方默认流程”，所有阶段配置立即还原为标准可用配置。
