# ISS-007：导入并长期管理可更新的网站脚本

## 目标与范围

用户能导入外部 AI 写好的网站脚本，保存到脚本列表，重复选择和更新。脚本负责网站注册行为及结果提取；界面不编辑脚本内部步骤。本任务交付可实际调用的插件接口，不是把旧流程 JSON 改名为脚本。

## 必要设计与依据

- 基于 `domain.py` 的 Adapter 调查可复用接口，制定最小脚本包和接口版本约定，说明网站标识、脚本标识/版本、入口、所需资源、运行参数、结果字段、进度事件、错误和结束清理。
- 框架提供邮箱/代理及日志能力，脚本不直接操作框架数据库或自己维护资源池；收信匹配条件由脚本表达。
- 导入校验与真正执行分离；无效入口、重复版本、不兼容接口、缺失依赖给出明确原因。说明支持的依赖范围，第一版不做任意环境自动安装系统。
- 更新失败保留可用旧版；运行中的任务固定使用启动时的版本，历史记录保留版本依据。
- 提供不访问真实网站的最小脚本示例和面向外部 AI 的编写说明，覆盖资源申请、日志、结果和失败返回。
- 包格式、加载机制及运行隔离方式待调查，在本 Issue 补充最终选择及理由。

## 验收方法

导入示例后重启仍可选择并调用；导入第二个不同输出的示例无需修改框架代码。无效包给出可操作错误且不污染列表；更新失败旧版可用，更新成功后新任务使用新版、历史仍指向旧版。契约测试覆盖清理和异常返回。
