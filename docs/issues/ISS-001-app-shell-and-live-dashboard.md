# ISS-001：实现现代化 Web 工作台框架、实时任务监控大盘与单任务抽屉详情

## 目标与范围

### 当前问题
目前 Web 界面采用简单的顶部按钮加长页面表格，缺少现代管理面板（如青龙面板 QingLong / Linear / Vercel Dashboard）的导航结构、批量勾选浮动操作栏、一键复制凭证反馈、实时运行槽位状态展示以及不打断上下文的侧滑详情抽屉（Drawer）。

### 期望行为
1. **现代化应用骨架（App Shell）**：
   - 左侧导航栏（含各功能模块入口、未完成/运行中角标计数、深浅色视觉层次）+ 顶部全局状态控制栏（当前批次选择器、运行状态呼吸灯、当前代理出口 IP 与换 IP 进度胶囊、一键启动/暂停/停止/导出按钮）。
2. **实时任务监控大盘与高交互数据表格（Data Table）**：
   - 顶部展示可视化的批次完成进度条（已完成含结果 / 已登录待拿结果 / 进行中 / 待处理 / 异常占比）及实时执行日志终端（支持自动滚动暂停、清空、按级别高亮）。
   - 任务表格支持：状态胶囊快速筛选栏、搜索框实时过滤、密码与最终结果（API Key / Token）单格**一键点击复制**（带 `已复制` 浮层反馈）、全局/单行明文显隐切换。
   - **多选浮动操作栏（Floating Bulk Action Bar）**：勾选任意数量的账号后，底部或表格上方浮现醒目的批量操作条（显示已选数量，提供「批量验证登录 & 拿结果」「批量设为已有账号模式」「批量重置重新注册」「清空选择」）。
3. **右侧滑出式任务详情抽屉（Slide-over Drawer）**：
   - 点击任意账号行或“详情/日志”按钮，从右侧滑出抽屉面板，展示该账号的完整生命周期时间线（`job_events` 从创建、发码、提交到拿 Key 的每一步时间与状态码）、关联代理节点、邮箱连接一键测试、以及单独修改该账号平台登录密码的操作框。

### 本次包含与排除的内容
- **包含**：Web 应用主框架、顶部全局运行栏、实时进度条与终端日志盒、高交互任务表格、浮动批量操作栏、右侧滑出详情抽屉、单账号密码修改 API。
- **排除**：可视化流程节点编辑器（见 `ISS-002`）、导号实时分列预览向导（见 `ISS-003`）、代理池测速墙（见 `ISS-004`）。

## 必要设计与依据

- **视觉与交互参考**：
  - 布局参考 **Linear / shadcn-ui Dashboard**：左侧固定宽 `230px` 导航栏，右侧自适应主内容区；色彩采用高对比度现代暗色/板岩色系（Slate/Zinc），状态标签区分明确（绿色=已拿结果、蓝色脉冲=运行中、琥珀色=待验证/待核查、红色=需人工处理/失败）。
  - 详情抽屉参考 **GitHub Actions / Playwright Trace Drawer**：右侧固定宽 `460px` 滑出层，带遮罩与 `ESC` 关闭支持。
- **接口与后端支撑（`src/agnes_provisioner/web.py`）**：
  - `GET /api/overview`：返回批次列表、状态统计、后台执行器状态与日志、代理换 IP 进度摘要。
  - `GET /api/jobs`：返回任务列表及凭证状态。
  - `GET /api/jobs/<job_id>/events`：返回任务审计事件时间线。
  - `POST /api/jobs/action`：补充 `action="set_password"` 支持在抽屉中直接更新指定账号的 `agnes_password` 或 `mailbox_password`（写入 `Vault`）。

## 验收方法

1. **框架与导航检查**：打开 Web 界面，点击左侧导航菜单切换各视图流畅无闪烁，顶部常驻栏实时展示当前批次与运行器状态。
2. **表格与浮动批量栏检查**：
   - 在任务列表勾选 2 个以上账号，观察是否立即出现浮动批量操作栏并显示已选数量。
   - 点击某行的 API Key 或密码旁边的“复制”按钮，确认剪贴板内容正确且界面出现复制成功提示。
3. **右侧详情抽屉检查**：
   - 点击任意任务的“详情/日志”，右侧滑出抽屉展示完整状态变更时间线；在抽屉内修改该账号密码并保存，开启明文显示后确认新密码已生效。
4. **异常情况**：当尚未创建任何批次就点击顶部“开始运行”时，界面弹出清晰友好的引导提示而非报 500 错误。
