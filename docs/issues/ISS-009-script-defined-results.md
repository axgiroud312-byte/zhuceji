# ISS-009：按网站脚本声明保存、展示和导出结果

## 目标与范围

结果不再固定为 Agnes API Key。脚本定义字段名称、类型和敏感属性；框架统一验证、保存并提供展示/导出接口。本任务负责数据闭环，主页整合由 ISS-011 完成。

## 必要设计与依据

- 基于 ISS-007 声明确定首版支持的字段类型、缺失值、必需字段及非法结果处理方式。
- 调查 `models.py`、`storage.py`、`vault.py`、`excel.py` 和 Web 导出路径；敏感结果继续加密保存、默认隐藏，不能把动态字段变成明文凭证旁路。
- 每条结果关联任务、网站、脚本版本及字段声明依据；脚本升级后历史字段仍可解释。
- 支持按批次查看和导出，保留失败状态与原因；结果缺失不伪造值。CSV 必须可用，既有 Excel 能力如依赖额外运行库应明确可用状态。
- 不要求用户编写提取正则或选择器；这些属于外部脚本。

## 验收方法

一个脚本输出账号/密码/API Key，另一个输出 Token/链接/数值字段，两者都能保存、重启读取并按声明导出。测试部分字段缺失、非法类型、失败任务、脚本版本变化、包含分隔符的内容及敏感字段显隐/导出；日志中不得出现敏感结果。
