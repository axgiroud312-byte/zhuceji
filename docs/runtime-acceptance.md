## Agnes、邮箱和代理验证范围

`test_real_browser_agnes_graph_and_http_proxy_closed_loop` 同时验证适配器和**完整 ScriptRuntime** 两条路径：真实 Chromium 经过本地 HTTP 代理访问受控注册站，Graph OAuth/邮件由受控响应提供；收到验证码后实际点击注册、身份核查、提取 Key。注册服务器检查资源消耗标记与任务提交标记均先于请求落库。再次执行不能重新注册；结果经过字段校验、DPAPI 保存、默认掩码及事件脱敏。

`test_legacy_bulk_proxy_uses_existing_local_upstream_relay` 实际建立本地上游 CONNECT → 代理网关链路，验证原 MeteredRelay、认证、固定 session 与关闭。其他测试覆盖代理失败/出口变化/TTL、邮箱凭证失败与耗尽、并发领取不重占、快照不受更新影响。

**外部真实服务尚未实测**：本轮未向真实 Agnes 注册账号，未刷新真实微软邮箱令牌，未请求供应商代理。当前外部凭证有效性、网站 DOM 的当日变化、供应商额度和长时间稳定性不能由受控测试证明。这是待真实环境验收范围，不记为模拟成功。

## 旧数据验证与保留

使用虚构旧用户、账号、加密凭证引用、代理、已成功任务、已提交未完成任务和未提交任务构造数据库副本。验证原 `users/batches/registration_jobs/accounts/proxies/proxy_meta` 内容逐行不变；结果可解密读取；旧待处理任务仅归档为 UNKNOWN/CANCELLED，不进入注册队列。重复迁移不重复创建；注入中途失败后事务回滚，原 Vault 未损坏，备份可读取，再运行能完成。

旧配置资源导入使用 SQLite `mode=ro`，复制邮箱及提交排除证据；测试逐字节核对源配置、数据库、Vault 不变，避免要求用户重新输入已有凭证。旧 mock 成功记录不消耗真实 Agnes 邮箱。

第一版脚本在本机服务进程内执行，独立任务 globals/参数和浏览器上下文；不是代码沙箱。异步超时为协作式，阻塞事件循环的脚本需人工终止服务；重启会保留中断记录且不重放。依赖必须预先安装，不自动安装系统软件。Excel 保持旧可选本机运行库能力，新工作台交付通用 CSV。
