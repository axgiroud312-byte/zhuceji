# 状态与持久化规则

## 当前脚本运行台（ISS-006）

新运行表使用 `rt_` 前缀，资源使用 `resource_` 前缀，不改写下方旧调度器表。一次启动事务创建指定数量的任务，运行入口每任务只调用一次。默认同网站并发 1，可配置 1～50；同一数据库的 OS RunLock 同时排斥其他网站、新批次和旧 CLI 调度器。进程退出后锁由操作系统释放。

PENDING → RUNNING → SUCCEEDED / FAILED / UNKNOWN。提交边界前失败为 FAILED，调用 `ctx.mark_submitted()` 后失败为 UNKNOWN；先写入邮箱消耗标记，再写入任务提交标记，然后才允许脚本发送注册请求。资源不可用时失败，不静默直连或换邮箱。停止后 PENDING 变 CANCELLED，已运行任务完成或达到异步 600 秒时限；清理上限 15 秒。

启动固定脚本版本、字段声明、参数和资源快照。相同 request_id 返回原批次，新的 request_id 在锁占用时拒绝。重启只在取得锁后恢复中断记录：已提交任务为 UNKNOWN，其余未完成任务为 CANCELLED，批次为 INTERRUPTED；绝不自动重新提交。

结果按照脚本字段验证，敏感值只在 Vault，数据库保存引用。日志按批次和任务存储时间/阶段/级别/消息/技术详情，用游标增量读取。脚本必须在首次使用敏感值前注册脱敏。历史批次保留原声明，CSV 导出包含状态、原因、网站、脚本版本和动态字段。

旧任务迁移成 ARCHIVED 批次，原表及 Vault 原引用保留；旧未完成任务不进入新队列。迁移前创建 SQLite/Vault 恢复副本，事务失败不改变原表，可重试。旧自定义流程仅保留源资料，不自动变成脚本。

## 以下为旧 CLI / 历史数据规则

状态名称和允许的变化以 `src/agnes_provisioner/domain.py` 的 `State`、`TRANSITIONS` 为准。

浏览器调用创建账号、发送邮箱验证码或创建 API Key 前，会先写入任务边界和审计事件。边界保存完成后才执行网页操作。如果程序在保存边界后中断，系统保留“结果未知”，避免自动重复提交。

提交前的网络故障可以有限重试；提交后的异常必须先核查。所有重试受 `max_attempts` 限制，平台限流的等待时间会保存在数据库中，程序重启不会清空等待时间。

邮箱验证等待、账号身份核查和 API Key 获取分别记录。账号成功需要匹配当前用户的登录证据。Excel 只有在取得实际 API Key 时显示“已完成”；已经确认账号但没有密钥时显示“账号已确认，缺 API Key”。

账号与任务由数据库唯一约束防止重复创建。相同用户在相同提供商下只能建立一个注册任务；再次创建批次会跳过已存在的任务。模拟任务与 Agnes 真实任务使用不同提供商标识，导出结果使用模拟标记。

调度器的进程锁防止同一个数据库被两个 Worker Pool 同时运行。批次控制状态、限流等待、注册阶段、尝试次数和审计历史都写入 SQLite。每次操作使用独立事务，并启用外键、WAL 和完整同步。

代理按任务领取独占租约。恢复已提交任务时保持原代理绑定；该代理不可用时进入人工处理。每个用户使用独立 BrowserContext。为恢复验证或登录而保留的临时会话状态加密保存，取得密钥后删除。

代理健康检查也使用独占且有时限的租约；恢复中断批次只释放该批次的任务租约，不清理健康检查或其他批次的租约。保留提交后绑定的节点不能删除、换轮或覆盖认证配置。代理内联账密使用当前 Windows 用户 DPAPI 加密，既有明文节点仅在显式重导入时升级。`0002` 数据库迁移只新增可空的代理延迟列，保留已有任务、代理与计数。

Excel 和含凭证 CSV 属于账号交付文件。默认导出隐藏邮箱和凭证；`--include-secrets` 才会写入密码和 API Key。Excel 预览隐藏凭证，导出过程产生的检查文件会移除。
